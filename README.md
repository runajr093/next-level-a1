# TypeScript Practice Problems


## Overview

This repository contains my TypeScript practice problems and solutions.
These problems helped me practice important TypeScript concepts, improve my problem-solving skills, and understand how to write reusable, type-safe functions.

## Topics I Covered

I practiced the following 8 problems:

 01  Multiply Value - Default Parameters, Optional Parameters, Function Return Types 
 02  Process Input - Union Types, Type Narrowing (typeof), Conditional Logic 
 03  Format Coordinate - Tuple, Readonly Modifier, Array Destructuring 
 04  Concatenate Arrays - Generics, Rest Parameters, Array Methods (flat) 
 05  Get Popular Courses - Interfaces, Array Filtering (filter), Object Types 
 06  Pluck Values - Generics, keyof, Indexed Access Types (T[K]), Array Mapping (map) 
 07  Employee and Manager Classes - Classes, Inheritance, Constructors, super(), Access Modifiers (protected and private) 
 08  Validate Age Async - Async Functions, Promises, resolve(), reject(), setTimeout(), Error Handling
